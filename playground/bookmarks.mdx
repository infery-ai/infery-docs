---
title: "Bookmarks"
description: "Pin important messages and revisit them across chats and projects."
---

Bookmarks let you save specific messages for later — a good answer, a useful code snippet, a promptyou want to reuse.

## Adding a bookmark

Hover over any message → click the **bookmark** icon. Works for both user and assistant messages. Bookmarks don't cost anything.

## Finding your bookmarks

Sidebar → **Bookmarks** tab. You see a flat list of all bookmarked messages across all chats and projects you have access to, with:

- The message content (text preview)
- Chat title and project name for context
- Timestamp
- A link to open the chat at that message

## Sharing

Bookmarks are **stored per-workspace**, not per-user — if someone else bookmarks a message you can see, it appears in their Bookmarks tab too (filtered to items they have chat access to).

## Removing

Click the bookmark icon again on the original message, or use the **×** on the bookmark tile.
