## What makes it different

- **Many models, one credit balance.** Stop juggling OpenAI, Anthropic, Google, xAI, DeepSeek and Alibaba invoices — the whole [catalogue](/models/catalog) meters to a single credit system.
- **One memory across chats.** The Studio carries what it learned about you from one conversation into the next, and shows you exactly what it recalled.
- **Whole workflows, not single calls.** [Workflows](/workflows/overview) run a chain of model calls, tools and HTTP steps on our side — one request in, one result out, with a cost estimate before it runs.
- **Workspace first, API second.** Your team signs in, organises work in projects, shares chats granularly — the API follows the same rules.
- **OpenAI-compatible where it can be.** Chat, embeddings, images and files work with the OpenAI SDK on a changed `base_url` — 7 operations unchanged, 4 with a documented divergence. The other 24 have no OpenAI equivalent to be compatible with, and are reached over plain HTTP or our own [SDKs](/sdks/overview). The [matrix](/sdks/openai-compatibility) is generated from the shipping operation list, so it cannot flatter us.
- **Operational safety nets.** Fallback chains run per workspace and per source model. Quotas and rate limits are set per API key. Budget alerts, MIME sniffing on file uploads and CAPTCHA on sign-up and every contact form come as standard.
